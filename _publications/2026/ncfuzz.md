abstract: >-
  Network services expose much of their behavior only under particular configurations, so a fuzzer that leaves the configuration space untouched never reaches large parts of the code. NCFuzz treats configuration as a first-class input dimension, using it to guide network service fuzzing toward states and code paths that conventional input-only fuzzing does not reach.
